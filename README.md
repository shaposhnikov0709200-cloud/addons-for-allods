# Аддоны для Аллодов Онлайн

Каталог аддонов для разных версий игры: описание возможностей,
инструкции по установке и сведения о совместимости.

## Каталог

| Аддон | Версия игры | Возможности | Проверка |
|---|---|---|---|
| [OpenAllBoxes](https://github.com/shaposhnikov0709200-cloud/OpenAllBoxes) | 4.0.02.42 | Массовое открытие сундуков, контроль свободных ячеек, прогресс и статистика добычи | Работа основного списка и подсказок подтверждена в игре; проверка остальных функций продолжается |

## Скачать

- [OpenAllBoxes 1.0.0](https://github.com/shaposhnikov0709200-cloud/OpenAllBoxes/releases/tag/v1.0.0) — скачайте архив аддона в разделе Assets.

## Установка

1. Выберите аддон для своей версии клиента.
2. Скачайте и распакуйте его архив.
3. Следуйте инструкции автора. Обычно папку аддона нужно поместить
   в `data/Mods/Addons` внутри папки игры.

## Совместимость

Совместимость указывается для каждого аддона отдельно.
Работа на одной версии клиента не гарантирует работу на другой.

Статусы проверки:
- **Проверено в игре** — есть подтверждение работы на указанной версии.
- **Заявлено автором** — совместимость указана автором.
- **Не проверено** — подтверждения пока нет.

## Авторы и лицензии

У каждого аддона свой автор и условия распространения.
Ссылки на оригинальные проекты и сведения о лицензиях сохраняются.
